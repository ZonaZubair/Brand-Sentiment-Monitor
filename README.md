# Brand Sentiment Monitor

A **Streamlit-based application** that performs real-time sentiment analysis on Reddit comments using **Hugging Face Transformers (LLMs)**.  
It allows **multi-brand selection**, adjustable limits, and provides **automated summaries, sentiment charts, and word clouds** for actionable insights.

---

## ⚡ Key Features
- Real-time sentiment analysis using **Hugging Face Transformers**  
- **Pie chart summary** of sentiment distribution (bright color scheme)  
- **Clean dashboard layout** with well-structured UI sections
